## About

I build intelligent systems — machine-learning pipelines, autonomous AI agents, and the real-time infrastructure that feeds them. My work sits where AI meets cybersecurity, with a decade's worth of side-quests through full-stack web and blockchain along the way.

- 🧠 **AI agents & NLP:** LLM agents that plan and act — security co-pilots, multi-agent narrative analysis, RAG pipelines — running on locally-hosted models, not just API calls.
- ⚙️ **Systems that ship:** production billing with automated payment reconciliation, live market-data scraping, real-time streaming pipelines, explainable AI for medical imaging.
- 📐 **Philosophy:** clean, modular, well-documented code — and systems that hold up against real data and real users.
